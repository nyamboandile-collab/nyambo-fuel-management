Backup & Recovery

Protect your Red Range Petroleum business records with a downloadable backup.

⬇️ Create Backup

The backup contains the business database records needed to recover the system, including garages, pumps, tanks, pump readings, sales, credits, payments, purchases, expenses, stock, suppliers, swipe collections and user profiles.

Keep the downloaded JSON file somewhere safe. Do not edit it.

♻️ Restore Backup

Warning: Restoring replaces the current business database records with the records in the backup file. This cannot be undone from the app. Only the Owner / Admin can perform a restore.

Recommended Backup Routine

Download a backup regularly, especially after entering large amounts of sales, payments, fuel purchases or other important records. Keep more than one backup copy in a safe location.

This app-level backup is an additional recovery measure. It does not replace Supabase's own database backup/recovery facilities.
